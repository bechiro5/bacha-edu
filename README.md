# مستودع اتفاق الباشا التعليمي

هذا المستودع هو **المرجع المركزي والوحيد** للدستور التربوي والتصميمي للمربي البشير السعيدي. تستخدمه أدوات الذكاء الاصطناعي بوصفه مصدر القواعد، ولا تنشئ قواعد موازية أو تستبدلها بذاكرتها الخاصة.

## الملفات المرجعية
- [الدستور التربوي والتصميمي الشامل](PEDAGOGICAL-RULES.md): اتفاق الباشا الحديدي، واتفاق RTL الصارم، واتفاق التتابع العمودي، والمراجعة الإلزامية قبل الإخراج.
- [قالب A4 RTL](templates/a4-rtl-template.html): قالب أولي تابع للدستور، وليس مصدرًا مستقلًا للقواعد.
- [تعليمات ربط أدوات الذكاء الاصطناعي](integrations/AI-TOOLS.md).
- [موصل Claude](integrations/CLAUDE.md).
- [موصل Gemini](integrations/GEMINI.md).
- [موصل ChatGPT](integrations/CHATGPT.md).

## قاعدة الحاكمية
الأولوية عند التعارض: تعليمات المستخدم الحالية الخاصة بالمهمة، ثم `PEDAGOGICAL-RULES.md`، ثم القالب، ثم اقتراحات الأداة. لا يجوز للقالب أو أي مهارة أو مساعد تغيير المحتوى أو القواعد من تلقاء نفسه.

## الهوية الافتراضية
- المدرسة: المدرسة الابتدائية الشهبانية
- إعداد: المربي البشير السعيدي
- المستوى: السنة الأولى ابتدائي

## سير العمل الإلزامي
1. قراءة أحدث نسخة من الدستور قبل أي إنتاج تعليمي.
2. قراءة القالب عند إنتاج HTML/A4.
3. نقل محتوى المستخدم حرفيًا دون حذف أو إضافة أو إعادة صياغة أو تغيير ترتيب.
4. مراجعة المحتوى والعربية والتشكيل والتدرج البيداغوجي والصور وRTL والتتابع العمودي.
5. عدم تجاوز ستة تمارين في الصفحة الواحدة، وعدم تصغير الخط لحشر المحتوى.
6. اختبار العرض والطباعة فعليًا قبل وصف الناتج بأنه جاهز.

**تنبيه:** القالب الحالي نقطة انطلاق أولية، ولم يُعتمد بعد بوصفه قالبًا مختبرًا للطباعة. يجب اختباره بصريًا وفي وضع الطباعة قبل استخدامه في إنتاج نهائي.
